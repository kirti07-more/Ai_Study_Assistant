# AI Study Assistant

A Python-based study assistant that helps users learn different topics through explanations, summaries, and quizzes.

## Features

- Explain a topic
- Make a summary
- Generate quiz questions
- Track quiz score
- Study multiple topics
- Exit option

## Supported Topics

Currently supported topics:

- Python
- Artificial Intelligence (AI)
- Machine Learning (ML)
- Data Science (DS)

## Technology Used

- Python

## 🚀 Future Improvements

- Add more study topics
- Connect an AI API
- Generate explanations dynamically
- Generate summaries and quizzes for any topic
- Convert the project into a web application
